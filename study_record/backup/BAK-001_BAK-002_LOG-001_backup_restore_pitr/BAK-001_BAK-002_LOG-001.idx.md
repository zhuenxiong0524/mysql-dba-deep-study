## 待证明结论

1. XtraBackup 8.4 能在线复制 MySQL 8.4 数据文件，并用并发捕获的 redo 把备份推进到一致状态。
2. 未执行 `--prepare` 的备份不能作为可启动数据目录；prepare 后才能 restore/copy-back。
3. 全量备份只能恢复到备份一致点；要恢复到误删前，还必须保留并按正确边界回放后续 binlog。
4. PG `pg_basebackup + WAL archive` 与 MySQL `XtraBackup + binlog` 的最终能力相近，但物理日志职责不同。
5. 增量备份、压缩/流式备份和 restore 都必须有完整性、空间、权限和停止条件。
