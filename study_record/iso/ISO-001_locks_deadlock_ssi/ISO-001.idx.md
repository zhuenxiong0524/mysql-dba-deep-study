# ISO-001 隔离级别、Gap/Next-Key Lock、死锁与 SSI

- 任务 ID：`ISO-001`
- 状态：`✅ 已完成（v1.0，2026-09-01）`
- 权重：`L`（深度机制，3 分）
- 基线：PostgreSQL 18.4 → MySQL 8.4.10 LTS
- 关联：MVCC-001（快照与可见性）；IDX-001（B+Tree 与索引记录）；ISO-002（MDL/在线 DDL）

## 研究目标

以 PostgreSQL RC/RR/SSI 为基线，理解 InnoDB Record/Gap/Next-Key/Insert Intention Lock，
能区分快照读与锁定读的“防幻读”，能从锁等待图诊断死锁，并能解释两边 RR 写偏差以及
PG SSI 与 MySQL SERIALIZABLE 的根本差异。
